# STATS-02 수익률 추이 그래프 정책 (#293)

## 범위와 데이터 기준

- 현재 SVG 그래프를 유지한다. 라이브러리 교체·추가 인터랙션·리디자인은 제외한다.
- `/api/stats/summary`의 `graph[].date`, `graph[].cumulativeProfitRate`를 사용한다.
- 값은 **가입 이후 누적 수익률(%)**이다. 일별 수익률·수익금·총자산이 아니다.
- 서버는 최근 정산일(KST)을 포함한 직전 7일을 시간순으로 제공한다.
- 투자·정산이 없는 날의 직전 누적 수익률 유지 값도 서버에서 제공한다.
- 프론트는 정상 응답을 재정렬·자르기·보간·미래 날짜 생성 없이 표시한다.
- 기준일은 서버가 준 날짜다. 데이터가 있으면 오늘 날짜로 대체하지 않는다.
- 그래프 표시 여부는 `graph` 데이터로 판단한다. `investDate`나 수익률의 부호·0 여부를 빈 상태 기준으로 쓰지 않는다.
- 원본 데이터를 변경하지 않는다. 비정상적인 비유한 숫자(`NaN`, `Infinity` 등)는 좌표 오류 방지를 위해 제외하며, 대체 값을 만들지 않는다.

## 데이터 개수와 빈 상태

| 경우                        | 표시                                              |
| --------------------------- | ------------------------------------------------- |
| 데이터 없음                 | 선·점 없이 축·격자·라벨 유지                      |
| 모든 값이 0%                | 모든 날짜의 점과 0% 수평선 표시                   |
| 앞부분에 0%가 있음          | 처음부터 마지막 날짜까지 모든 점 연결             |
| 양수·음수·중간 0%           | 실제 값을 유지하며 연결                           |
| 데이터 1개                  | 해당 날짜의 점을 그래프 가로 중앙에 표시, 선 없음 |
| 2~6개 등 일부 데이터만 수신 | 받은 날짜·점만 표시. 임의로 7개로 채우지 않음     |

- 데이터가 없는 경우에만 **KST 오늘 포함 직전 7일**을 오래된 날짜부터 표시한다.
- 빈 상태와 전체 0% 상태의 Y축 기본 범위는 기존 `0~10%`를 유지한다.
- 조회 실패는 빈 데이터와 다르다. 오류 팝업·재시도·캐시 유지 정책은 별도 오류 처리 작업에서 다룬다.

## X축

- 날짜는 `5/7`처럼 월/일만 표시한다. 연도·앞자리 0은 표시하지 않는다.
- 각 날짜와 점은 동일한 인덱스를 사용한다. 일반적인 7일 응답은 하루 간격으로 배치한다.
- 모든 데이터 점과 격자는 유지한다. 기본적으로 날짜 라벨도 모두 표시한다.
- 너비가 부족해 라벨이 겹치면 중간 라벨의 표시 간격만 늘린다. 첫 날짜·마지막 날짜는 유지한다.
- 날짜 라벨을 줄이더라도 원본 데이터와 선·점을 줄이지 않는다.

## Y축

- 모든 라벨에 `%`를 붙인다. `k`, 원화 단위는 사용하지 않는다.
- 음수 값도 절댓값으로 바꾸지 않고 그대로 표시한다.
- 데이터 최소·최대와 0을 포함하고, 값이 경계에 닿지 않도록 범위에 여유를 둔다.
- 기존 작은 값 구간 정책(`-1~1%` 데이터의 축 범위 `-2~2%`)을 유지한다.
- 격자는 기존 4구간·5개 라벨을 유지한다. 축 라벨은 소수 최대 둘째 자리까지 표시한다.
- 실제 점의 값은 라벨 반올림과 별개로 서버 숫자를 사용한다.
- Y축 라벨의 실제 폰트 폭을 측정해 왼쪽 여백을 확보한다. 큰 값에서도 부호·숫자·%가 잘리지 않아야 한다.

## 레이아웃과 접근성

- 기존 높이 `200px`, 최대 너비 `291px`를 유지하되 부모보다 넓어지지 않는다.
- SVG 좌표 너비는 실제 컨테이너 너비를 사용한다. 화면을 `390px`로 고정하지 않는다.
- 창 크기와 폰트 로딩 완료 후 글자 폭을 다시 측정한다. 축 글자를 임의로 축소하지 않는다.
- 기존 선·점·격자·축의 디자인 토큰을 유지한다.
- 그래프에는 접근 가능한 이름과 날짜별 수익률 설명을 제공한다.

## 검증

자동·모의 응답 검증은 프론트 표시 동작을 확인하며, 실제 서버의 집계 정확성을 보장하지 않는다.

### 함께 적용한 오류 복구 정책

- STATS-02 최초 실패는 재시도만 제공하고 닫기는 허용하지 않는다.
- STATS-03·08 최초 실패의 닫기는 시트 종료 또는 이전 화면 이동으로 처리한다.
- 기존 데이터가 있는 재조회 실패는 화면을 유지한 채 팝업을 표시한다. 닫아도 기존 데이터를 유지한다.
- 기간·정렬 변경 요청 실패 시에도 마지막 성공 데이터를 보존하며, 이전 결과를 새 기간 데이터처럼 표시하지 않는다.
- 재시도 성공 시 팝업은 자동 해제한다. 닫은 뒤 새로운 조회가 실패하면 다시 안내한다.
- 통계 오류 팝업만 바텀시트보다 위에 표시하고 재시도 버튼으로 포커스를 옮긴다.
- 401은 공통 인증 재발급·로그인 이동 처리에 맡기며 별도 통계 오류 팝업을 중복 노출하지 않는다.

## 서버 계약 및 실데이터 확인 대기

- `investDate`가 실제 정산 처리일인지 정산 대상 투자일인지 확정 전까지 응답 날짜를 그대로 사용한다.
- 장기간 미투자 후 재개한 계정에서, 새 정산 이후 7일 범위가 이동하고 범위 이전 누적 손익도 유지되는지 확인한다.
- 미투자일이 직전 누적값을 유지하고, 마지막 그래프 값이 같은 응답의 `cumulativeProfitRate`와 일치하는지 확인한다.
- API 문서의 빈 상태 설명(`graph: []`)과 예시(0% 7개)가 다르다. 확정 전에는 둘 다 렌더링 가능하게 하되 실제 0%를 임의로 빈 상태로 바꾸지 않는다.
- 서버 기준일과 화면의 ‘최근 7일’ 문구를 어떻게 구분할지는 의미 확정 후 반영한다. 오늘 기준으로 날짜를 옮기거나 값을 채우지 않는다.
